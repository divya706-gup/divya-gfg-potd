# GeeksforGeeks Problem of the Day (POTD) 🎯

Welcome to my repository dedicated to solving the *GeeksforGeeks (GFG) Problem of the Day*. This repository serves as a personal archive of daily coding challenges, helping to track consistency, improve problem-solving skills, and master data structures and algorithms (DSA).

## 🚀 Repository Structure

Each solution is organized systematically. You can find solutions categorized by their respective problem names or dates.

- *Language Used:* C++
- *Topics Covered:* Arrays, Strings, Linked Lists, Trees, Graphs, Dynamic Programming, and more.

## 🛠️ How to Navigate

1. Browse through the repository folders to find the problem solution you are looking for.
2. Inside each problem folder/file, you'll find:
   - The problem statement or a link to it.
   - My optimized solution with comments explaining the approach.
   - Complexity analysis ($O(N)$ time, $O(1)$ space, etc.).
